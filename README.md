# Gamified Learning Interaction

## Overview
This project is an interactive gamified learning prototype inspired by Tic Tac Toe gameplay mechanics. The interaction was developed to explore learner engagement strategies, conditional logic handling, and interactive learning experiences within eLearning environments.

The project demonstrates how gamification concepts can be integrated into digital learning experiences using interactive logic and user-driven gameplay.

## Features

- Interactive gameplay mechanics
- Dynamic win/lose conditions
- Restart functionality
- User interaction handling
- Responsive interaction flow

---

## Skills Demonstrated

- Gamification concepts
- Storyline variables & triggers
- User interaction handling
- Interactive learning design
